# حريق سوق المدينة بحلب القديمة · 26 أيلول 2012
## منصة تحقيق استقصائي وتوثيقي لتاريخ وجريمة إحراق سوق المدينة التراثي

مشروع توثيقي غامر يروي تفاصيل جريمة إحراق سوق المدينة المسقوف في حلب القديمة المدرج على قائمة التراث العالمي لدى اليونسكو، إثر القصف العشوائي لعصابة الأسد في خريف 2012، مع إبراز صمود الحجر الحلبي وإرادة البناء السورية الحرة.

---

### التقنيات المستخدمة
* **الهيكل:** HTML5 دلالي متكامل مع محددات الوصولية WAI-ARIA.
* **التنسيق:** Vanilla CSS3 حديث بالكامل عبر التوكنات والمتغيرات البصرية، دون أي مكتبات خارجية.
* **البرمجة التفاعلية:** Modern ES6+ JavaScript بدون أي تبعيات.
* **النماذج التفاعلية:** ربط حقيقي مباشر مع Web3Forms بالمفتاح الرسمي المعتمد.

### الخطوط والتراخيص
* `Cairo-Bold.woff2` (Cairo Family) — رخصة الخطوط المفتوحة SIL Open Font License (OFL).
* `Tajawal-Regular.woff2` و `Tajawal-Medium.woff2` (Tajawal Family) — رخصة الخطوط المفتوحة SIL Open Font License (OFL).
جميع الخطوط مخزنة محلياً في مجلد `fonts/` دون أي اتصال بخدمات خارجية.

### الأصول والشعارات
* شعار العقاب الرسمي السوري المعدني: `images/eagle-emblem-metal.svg` بنسبة مقفلة 1000 : 754.1 وحيّز أمان لا يقل عن 25%.
* التوقيع الرسمي المعتمد: `@𝓚𝓱𝓪𝓵𝓭𝓸𝓾𝓷𝓐𝓴𝓻𝓪𝓶𝓪𝓱`.

### التشغيل المحلي
افتح ملف `index.html` مباشرة في أي متصفح ويب حديث، أو شغّل خادم محلي:
```bash
python3 -m http.server 8000
```
ثم توجه إلى `http://localhost:8000`.
